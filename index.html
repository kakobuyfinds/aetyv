What to check before you order

Verify the original listing

When comparing ACBuy finds, save the original seller link and item ID together. For a Weidian product link, check the seller name and selected color on the listing. For a Taobao item, open the variant menu to confirm the size is offered. On 1688, check the minimum order quantity before comparing prices.

If you found the item through an AllChinaBuy spreadsheet, keep the marketplace ID in your notes so you can match it across directories. Save a screenshot of the selected variant and seller return terms in case the listing changes.

Compare measurements by category

  • Shoes: Use the seller’s shoe size chart and compare insole length in centimeters, especially when converting between US, UK and EU sizes.
  • T-shirts, hoodies and jackets: Compare flat chest width, shoulder width, sleeve length and garment length with a piece you already wear.
  • Pants, shorts and sets: Check flat waist, rise and inseam. Confirm whether you can choose different sizes for the top and bottom.
  • Headwear, underwear and jerseys: Check the cap’s adjustable circumference, whether the waistband is measured stretched or relaxed, and whether the jersey allows room for a layer.

Read the ACBuy QC photos

When warehouse QC photos are available, match the size label and colorway to your order. For sneakers, compare heel alignment, toe-box shape and both outsoles. For apparel, check seams and print placement. For bags and jewelry, ask for close-ups of zipper pulls, clasps and corners if the overview leaves those details unclear.

Ask for a ruler photo when a garment measurement matters. Record any discrepancy and check the exchange deadline before approving the parcel for shipment.

Estimate the ACBuy shipping cost

Record the item cost, domestic delivery and any agent fees first. Once packed dimensions are available, compare actual parcel weight with the carrier’s dimensional weight calculation. Ask for a new quote if removing a shoe box changes the parcel dimensions.

Use your destination postcode for a shipping quote and include any applicable import VAT, duties and handling fees when estimating the landed cost. Compare delivery windows and tracking options for the same destination.

Frequently asked questions

What is an ACBuy spreadsheet?

An ACBuy spreadsheet is a directory people use to save and compare product links before ordering through a shopping agent. This independent CAFANS guide provides category shortcuts and a checklist for reviewing listings.

How do I check if a seller link is still valid?

Open the original listing and match the item ID, seller name, color and size. If the link redirects to a different product or the variant has disappeared, look for a current listing before you buy.

Can QC photos prove a branded item is authentic?

QC photos can show visible details such as stitching, labels and condition. For branded goods, verify the seller and provenance through a trusted source. Use an independent authentication service if you need additional evidence.

How do I estimate international shipping costs?

Use the packed parcel’s weight and dimensions to compare quotes for your destination. Check the carrier’s billing rules and include applicable taxes, duties and handling fees in your estimate.
